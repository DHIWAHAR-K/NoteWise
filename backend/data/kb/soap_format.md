# SOAP Note Format

## Overview
SOAP is the standard structured format for clinical documentation:
- **S** — Subjective: Patient's chief complaint, history of present illness (HPI), review of systems (ROS), past medical/surgical/family/social history
- **O** — Objective: Vital signs, physical examination findings, lab/imaging results
- **A** — Assessment: Diagnosis or differential diagnoses, clinical impression
- **P** — Plan: Treatments ordered, medications prescribed, referrals, follow-up, patient education

## Subjective section — key elements
- Chief complaint (CC): patient's words in quotes
- HPI: OLDCARTS mnemonic (Onset, Location, Duration, Character, Alleviating/Aggravating factors, Radiation, Timing, Severity)
- Current medications with doses
- Allergies

## Objective section — key elements
- Vital signs: BP, HR, RR, Temp, SpO2, Weight/BMI
- General appearance
- System-specific examination findings
- Pertinent labs and imaging with values and reference ranges

## Assessment section — key elements
- Primary diagnosis with ICD-10 code if applicable
- Active problem list updates
- Differential diagnoses considered

## Plan section — key elements
- Medications: new prescriptions, changes, discontinuations with reasoning
- Orders: labs, imaging, procedures
- Referrals: specialty, urgency
- Patient education: counseled on diagnosis, medications, red flags
- Follow-up: timing and conditions for return
